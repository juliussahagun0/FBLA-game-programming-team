## 1. Features

| Feature | Need it serves | Group | Size | Owner |
| --- | --- | --- | --- | --- |
| A player can open the game, read the rules on the title screen, and start a new season. | Gives players a clear starting point and explains how to play right away. | Must-have | S | |
| A player can recruit new athletes and assign them to practice drills to boost their stats. | Lets players build and train their high school roster over the season. | Must-have | M | |
| A player can move, attack, and block with an athlete in a sandbox fighting arena. | Delivers the core fighting gameplay and responsive controls. | Must-have | L | |
| A player can play through scheduled season matches against AI teams to reach the state championship. | Drives the main goal of competing through a season to win the title. | Must-have | M | |
| A player can finish a season with different endings, like winning the state title, missing the playoffs, or losing the locker room. | Shows how a player's choices lead to multiple outcomes. | Must-have | S | |
| A player can balance tough practices with rest days so athletes don't burn out or get hurt. | Adds resource and stamina management to team planning. | Should-have | M | |
| A player can make tough calls during random off-field problems, like grade checks, minor injuries, or budget cuts. | Challenges players to handle unexpected obstacles and keep morale up. | Should-have | M | |
| A player can jump into a sandbox practice mode to set up custom hazards and test out combos. | Gives players freedom to experiment with mechanics outside of official matches. | Should-have | L | |
| A player can turn on accessibility options like colorblind indicators, custom keybinds, and difficulty settings. | Makes the game easier to play and navigate for everyone. | Should-have | S | |
| A player can scout rival schools before big matches to learn their fighting styles and tweak their lineup. | Rewards strategic preparation before tough games. | Stretch | M | |
| A player can unlock custom uniforms, mascots, and trophies that carry over across multiple seasons. | Adds long-term progression and visual customization. | Stretch | L | |
| A player can grab a second controller or share a keyboard for local two-player exhibition fights. | Lets friends test out rosters against each other on one screen. | Stretch | M | |
## 2. Rating sheet check

| Rating sheet line | Where our plan covers it |
| --- | --- |
| **Game/simulation addresses all parts of the concept/topic and guidelines** (15 pts) | **Road to the Championship theme:** Players act as a high school athletic coach/director recruiting athletes, running practices, managing budgets/resources, maintaining team morale, handling random season events, and competing toward the state title. |
| **Game/simulation rules are well-defined and clearly explained** (5 pts) | Built-in "How to Play" screen accessible from the title menu, in-game tooltips explaining win/loss conditions, and a dedicated rules walkthrough in our presentation. |
| **Game/simulation is challenging, but can be completed** (5 pts) | Balanced resource/morale trade-offs across the season with **multiple distinct endings** (e.g., State Champions, Playoff Runner-Up, Missing Playoffs, or Fired for Low Morale/Budget Deficit). |
| **Innovation and creativity of the game/simulation** (5 pts) | [Insert your unique twist—e.g., dynamic player chemistry system, interactive halftime play-calling mini-game, or branching press conference dilemmas]. |
| **Describes programming language selection, graphic design tools, game engines, or other software used and evaluates technical complexity** (5 pts) | Built using **[Your Engine/Language, e.g., Godot / GDScript or Unity / C#]** and **[Art/Audio Tools]**. Presentation slides include system architecture, core algorithms (e.g., game simulation math), and future improvements. |
| **Graphics & game assets are appropriate for concept and/or topic** (5 pts) | Custom high school sports visuals (locker room, practice field, stadium scoreboard, player cards) created in **[Your Art Tool, e.g., Aseprite / Figma]** and explained during our demo. |
| **Graphics & game assets are consistently applied** (5 pts) | Unified color palette, consistent pixel/vector art style, and matching UI button/card layouts across every screen. |
| **Graphics & game assets quality and consistency enhance overall user experience** (5 pts) | High-contrast text for readability, clean UI hierarchy, and fitting sports audio effects/background music with volume controls. |
| **Title screen functions & provides clear instructions** (5 pts) | Functional Title Screen featuring **Start Game**, **Instructions/Rules**, and **Settings** buttons, allowing new players to read rules or returning users to launch immediately. |
| **UX Design: User journey, design rationale, accessibility features** (5 pts) | Designed for intuitive single-screen management; includes **accessibility features** (e.g., colorblind-friendly status indicators/icons, scalable text or high-contrast mode, and full keyboard/mouse support). |
| **Users can easily navigate between pages, and overall user engagement and enjoyment are considered** (5 pts) | Clear top/bottom navigation bar switching seamlessly between Roster, Practice, Budget, and Game Day screens with instant visual feedback. |
| **Game/Simulation controls & mechanics are intuitive** (5 pts) | Simple point-and-click / keyboard controls with clear hover states, confirmation prompts, and responsive feedback. |
| **Presentation Delivery & Protocols** (40 pts total: Organization, Poise, Q&A, Event Guidelines) | Rehearsed 7-minute script with all team members speaking, offline local build ready (no reliance on venue Wi-Fi), max 3 devices, built-in laptop speakers only, and documented sources/credits. |
